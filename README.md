# pdf2image

これは PDF ファイルを画像に変換する Discord Bot です．
Discord で PDF ファイルがプレビューできたら便利なのになー．

## 招待 URL

https://discord.com/api/oauth2/authorize?client_id=1103559284572291162&permissions=274878008320&scope=bot%20applications.commands

## 使い方

### メッセージから変換する

PDF ファイルが添付されたメッセージのコンテキストメニューから アプリ > PDF を選択すると画像に変換されたものが返信されます．
PDF ファイルが複数添付されている場合は，変換する PDF ファイルを選択できます．

### スラッシュコマンドで変換する

`/pdf` の `file` に PDF ファイルを添付して実行すると，PDF ファイルが投稿され，画像に変換されたものが返信されます．
